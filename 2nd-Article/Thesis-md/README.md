## 📝 File Descriptions

### 📘 Core Material
- **00_Phd_Topic_Evaluation.md**  
  Contains Perplexity’s deep research evaluation of the topic and novelty justification.

- **01_Literature_Review_Base.md**  
  The thematic literature base organized by pillars (routing, sustainability, self-healing, 6G, disaster monitoring).

- **02_Detailed_Paper_Extraction.md**  
  The detailed extracted summaries (objective, method, results, limitations) of 27 academic works.

- **03_Literature_Review_Text.md**  
  Polished narrative paragraphs for the Literature Review chapter.

- **04_Gap_Analysis_Tables.md**  
  Gap analysis and comparison tables supporting the research gap.

### 📌 Future Chapters
- **05_Baseline_Code_Discovery.md**  
  Will contain baseline implementation repositories and simulation tools.

- **06_Methodology.md**  
  Description of proposed model, algorithms, evaluation setup, metrics.

- **07_Experiments_Results.md**  
  Experimental results and performance comparisons.

- **08_Discussion_Conclusion.md**  
  Broader discussions, implications, and thesis conclusions.

## 📌 How To Use

1. Keep all Markdown files up to date as you progress.

4. Populate subsequent MD files with content as you complete research steps.
